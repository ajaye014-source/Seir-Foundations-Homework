What I Did
Created a Master Blueprint: After re-doing the lab with my study group, I made a launch template (basically a cookie-cutter setup for a virtual computer). Using that single template, I created three identical cloud computers all at once.

Tested Each Computer: I logged into the first machine using the web browser connection, noted its unique IP address, snapped a screenshot, and logged off. I repeated the exact same steps for the second and third machines.

Explored the Dashboard: Once logged out of all three, I clicked around the Amazon Web Services (AWS) control panel to check out the details tab, system status, and alert settings.

Cleaned Everything Up: I selected all three machines and completely deleted (terminated) them. I refreshed the screen to double-check that they were completely gone so I wouldn't get charged for running them.

What I Learned
Templates Save Time: Using a template is like saving a standard company software setup. Instead of building every new computer from scratch, you click one button to create a ready-to-use virtual machine.

Computer Health Checks: Keeping an eye on CPU usage, memory, disk activity, and uptime tells you if a computer is struggling or running smoothly. Heavy workload spikes aren't always a bad sign—sometimes it just means a lot of people are logged in at once (like during month-end reporting).

Stopping vs. Deleting: Just "turning off" a cloud machine still leaves its hard drive active, which costs money. You have to fully terminate (delete) the machine to stop all charges
